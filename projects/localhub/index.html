01

어떤 경험을 만들고 싶었나요?

광주·전라 지역의 관광지, 음식점, 숙박 등 공공데이터를 바탕으로 지역정보를 탐색하고 공유하는 커뮤니티를 만들었습니다. 정보를 읽는 데서 끝나지 않고 지도에서 위치를 보고, 이동 경로를 확인하고, AI에 여행 경로를 물어볼 수 있도록 기능을 연결했습니다.

02

제가 맡은 부분

데이터를 바탕으로 지도 API와 경로 API를 연동했습니다. GPT API를 연결한 챗봇과 AI 경로 추천 기능을 만들고, 사용자가 각 기능으로 이동할 수 있는 메인 페이지와 버튼, 배경을 구현했습니다.

프로젝트 전 과정에서 AI를 활용해 개발했습니다. 필요한 기능과 화면 흐름을 정하고, AI가 생성한 코드를 활용해 기능을 연결하는 방식으로 진행했습니다.

03

프로젝트의 범위

Vue.js 3 기반의 프론트엔드 팀 프로젝트로, 제공된 JSON 데이터를 활용했습니다. 커뮤니티 기록은 브라우저 저장소를 사용하는 실습 구조였으며, 지도·챗봇·추천 기능과 첫 화면이 제 담당 범위였습니다.

04

이어지는 아이디어

지역 탐색 경험을 확장해 GPS 방문 기록을 디지털 도장으로 모으고, 이를 여행 코스로 조합하는 ‘Local Explorer’를 기획했습니다. 방문 시간차 검증과 일정한 JSON 형식의 코스 저장을 고민했습니다. 이 확장안은 구현 완료 기능과 구분되는 기획 아이디어입니다.
